# Subtitle Shield

Subtitle Shield 是一个面向语言学习者的 YouTube 和 Bilibili 字幕辅助脚本。它通过给字幕增加一点可逆的阅读阻力，帮助你先听，再在需要时临时查看字幕。

## 功能

- 支持 YouTube 和 Bilibili。
- 支持全局启用/禁用，也支持分别控制两个站点。
- 字幕模式包括模糊、倒置、隐藏、仅暂停时显示、延迟显示。
- 可配置模糊强度、延迟时间和 Bilibili 字幕位置偏移。
- 按住快捷键可以临时显示字幕。
- 可选鼠标悬停字幕区域时显示。
- 页面内配置面板支持拖动、关闭和最小化为悬浮球。
- UI 支持中文和英文。

## 使用

安装脚本后打开 YouTube 或 Bilibili 视频页，在用户脚本管理器菜单中选择“打开配置面板”。你可以在配置面板里调整字幕模式、快捷键行为、站点开关和位置偏移。
